# AI JobHub

A modern job discovery platform built with Next.js (React, TypeScript), Tailwind CSS, FastAPI, and Supabase.

## Quick Start

1. Install dependencies for the frontend and backend.
2. Configure Supabase environment variables.
3. Run `npm run dev` for the frontend and `uvicorn app.main:app --reload` for the backend.

## Project Structure
```
ai-jobhub/
├─ frontend/          # Next.js app
├─ backend/           # FastAPI service
├─ infra/             # Supabase schema & migrations
├─ docker-compose.yml # Optional Docker compose for local dev
├─ README.md          # This file
└─ .gitignore
```
